# finish

현재 작업을 마무리해줘. 아래 순서를 반드시 지켜서 끝까지 진행해.

1. 변경사항 점검

- git status, git diff(스테이징 포함), 최근 커밋 로그 확인
- 이번 작업과 무관한 파일은 커밋에서 제외

2. 빌드/검증

- npm run build 실행
- 실패하면 원인 수정 후 다시 build 성공시켜

3. 커밋

- 필요한 파일만 git add
- 커밋 메시지는 한국어로 작성
- 형식:
  - 제목: 한 줄 요약
  - 본문: 왜 변경했는지 1~2문장
- 커밋 후 git status로 깨끗한지 확인

4. 브랜치/푸시

- 현재 브랜치가 main이면 feature/로 새 브랜치 생성 후 진행
- 원격에 push (-u 포함 필요한 경우)

5. PR 생성

- gh pr create로 PR 생성
- PR 본문 형식:
  - ## Summary (핵심 2~4개 bullet)
  - ## Test plan (실행/확인한 항목 체크리스트)
- 생성된 PR URL을 마지막에 알려줘

6. 최종 보고

- 커밋 해시
- 푸시 브랜치
- PR URL
- 빌드 성공 여부
