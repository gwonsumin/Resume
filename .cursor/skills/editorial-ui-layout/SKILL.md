# editorial-ui-layout

## Instructions
- Use editorial-inspired layout structure
- Preserve strong whitespace and hierarchy
- Typography should drive the layout
- Maintain modular spacing rhythm
- Use clean alignment and balanced composition
- Prioritize readability over decorative styling
- Maintain breathable spacing between sections
- Preserve visual pacing throughout the page

## Typography Rules
- Strong title hierarchy
- Clear subtitle structure
- Quiet body text
- Consistent line-height and spacing

## Layout Rules
- Avoid overly dense UI composition
- Avoid excessive decorative graphics
- Keep visual rhythm balanced
- Preserve asymmetrical editorial balance when intended

## Avoid
- Tight spacing
- Overloaded layouts
- Random alignment
- Equal visual weight everywhere
- Generic dashboard feeling
