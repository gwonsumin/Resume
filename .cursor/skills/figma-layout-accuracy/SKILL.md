# figma-layout-accuracy

## Instructions
- Figma 레이아웃을 정확히 따른다
- 간격, 정렬, 계층 구조를 준수한다
- 디자인 레퍼런스의 구성 균형을 유지한다
- 임의로 레이아웃 비율을 변경하지 않는다
- 시각적 밀도를 최대한 동일하게 맞춘다
- 패딩과 갭 구조를 정확하게 유지한다
- 크기를 추측하지 않는다
- 타이포그래피 계층 구조를 일관되게 유지한다
- 의도된 여백과 breathing space를 보존한다
- 섹션 비율을 디자인 레퍼런스와 정렬한다

## Priority
- Layout accuracy
- Spacing consistency
- Typography hierarchy
- Composition balance

## Avoid
- Random spacing changes
- Arbitrary resizing
- Overcrowded layouts
- Generic UI restructuring
