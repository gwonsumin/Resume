# ux-portfolio-storytelling

## Instructions
- This project is a UX portfolio, not a generic landing page
- Each section should communicate a UX narrative
- Prioritize flow, readability, and emotional pacing
- Maintain storytelling consistency between sections
- Focus on UX meaning rather than decorative visuals
- Preserve the "state -> selection -> flow" concept
- Sections should feel connected emotionally and structurally
- Maintain brand experience throughout the page

## Focus
- UX narrative
- Emotional flow
- Interaction meaning
- Brand consistency
- User-focused storytelling

## Avoid
- Template-like layouts
- Generic portfolio patterns
- Decorative-only interactions
- Excessive UI elements
- Overly corporate design
